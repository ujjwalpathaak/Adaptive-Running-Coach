# Adaptive Running Coach — UI

React (Vite + TypeScript) dashboard for Adaptive Running Coach.

## Setup

```bash
npm install
npm run dev
```

Runs on http://localhost:5173 and proxies `/api` to the backend at http://localhost:4000.

## Pair with backend

Use [Adaptive-Running-Coach-BE](https://github.com/ujjwalpathaak/Adaptive-Running-Coach-BE).
