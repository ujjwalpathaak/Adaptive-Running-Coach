# Running Plan Guide — Learnings

Source: [How to Build a Running Plan (Sovereign Athletic / SVGN)](https://svgn.com.au/guides/running-plan-guide)

Practical coaching principles distilled for Adaptive Running Coach. Use this as a design reference when structuring plan creation, weekly templates, progression, and adaptation rules.

---

## Core idea

A plan should make the week **easier to understand**:

- Where the key sessions sit
- How easy work supports hard work
- How to build capacity without losing control of the week

The athlete must be able to **execute, recover from, and repeat** the plan.

---

## Individual profile (inputs a good plan should respect)

| Factor | Why it matters |
|--------|----------------|
| Training age | Beginner vs established base |
| Current weekly volume | Anchor for progression |
| Strength / other load | Limits recoverable running |
| Life stress, sleep | Absorptive capacity |
| Previous exposure | Durability |
| Injury history | Risk caps |
| Race goal | Session selection |
| Current fitness | Pace + volume floors |
| Available training days | Week shape |
| Terrain / environment | Pace context |
| Response to intensity | When to push vs hold |

Same principles, different application. Two athletes should not get identical weeks by default.

**V1 implication:** We already use last-3 runs + race goal + training days. Later: injury flag, strength days, sleep/stress proxies.

## Start with the goal

Goal sets direction. Ask (or capture):

1. What distance / event?
2. How many run days per week?
3. Other training load (strength, hybrid)?
4. Current weekly volume?
5. What can they repeat without excessive soreness?
6. What improves first: consistency, speed, endurance, or race-specific capacity?

**The plan serves the outcome** — session types follow the goal.

**V1 implication:** Race distance + goal time + date + days/week are the goal block. Add an explicit “primary gap” later (consistency vs pace vs endurance).

## Establish a running anchor (pace reference)

Before prescribing paces, establish a **field anchor** from current fitness — not from race fantasy.

Useful anchors:

- Consistent 60-minute run
- Consistent 10km
- Recent race or controlled time trial
- Well-paced session that reflects current fitness

Requirements: even pacing, controlled hard effort, limited surging.

This estimate (often treated as **threshold / T-Pace**) guides:

- Easy running
- Threshold work
- Faster intervals
- Race-specific sessions

Retest roughly every **8–12 weeks** under similar conditions.

**VDOT / calculators:** useful for pace relationships and goal demands; estimates only — combine with athlete feedback and current training.

**V1 implication:** Last-3 median pace is our current anchor. Prefer anchoring training bands to that field estimate, then blend slowly toward race goal (already started). Later: explicit T-Pace from a designated test run or best recent 10k.

---

## T-Pace as programming language

T-Pace ≈ controlled hard pace that is strong and repeatable.

Program relative to it:

- At T-Pace
- Slightly faster / slightly slower
- Easy relative to T-Pace
- Race-specific paces
- Adjusted by feedback

Pace data = structure. Athlete feedback = context. Both matter.

**V1 implication:** Map our bands roughly as:

| Band | Relative to anchor |
|------|--------------------|
| Easy | Clearly slower than T / current hard |
| Long | Easy–steady, near current long effort |
| Quality | Near or slightly faster than current strong pace (not race goal overnight) |

## Basic weekly structure (minimum strong week)

Most recreational / hybrid athletes: **three runs per week**

1. **Short easy** — frequency, low-stress aerobic volume  
2. **Quality** — one clear intensity stimulus  
3. **Long easy** — time on feet, durability  

This leaves room for strength, life, and recovery.

### Session intents

**Short easy (20–35 min)**  
Purpose: aerobic capacity, consistency, recovery support, tissue tolerance, relaxed mechanics.  
Feel: controlled; finish able to do more. Beginners: run-walk OK.

**Quality (main intensity)**  
One stimulus: speed, threshold, VO₂, race pace, hills, or efficiency — depending on goal.  
Examples:

- Beginner fartlek: 10×1 min steady / 1 min easy  
- Intervals: 5×3 min strong / 2 min easy  
- Threshold: 3×8 min controlled hard / 2 min easy  
- VO₂: 6×2 min hard / 2 min easy  

Must still allow recovery for the rest of the week. For hybrid athletes, **one quality run/week** is often enough.

**Long easy (40–75+ min by history/goal)**  
Purpose: aerobic base, low-intensity efficiency, durability, confidence.  
Feel: composed and controlled. Value = time + rhythm + repeatability.

**V1 implication:** Our template already approximates easy / quality / long / rest. Prefer **time or distance floors from calibration**, not race-distance fantasy. Quality should be structured (reps) over time, not just “shorter fast continuous.”

## Spacing the week

Rhythm matters as much as content.

Practical rules:

- Separate quality from heavy lower-body strength when possible  
- Give key sessions enough space to be performed well  
- Keep easy runs **genuinely easy**  
- Place long run where recovery follows  
- Match difficulty to recovery ability  

Example pattern (illustrative only):

| Day | Example |
|-----|---------|
| Mon | Strength / hybrid |
| Tue | Short easy |
| Wed | Strength / conditioning |
| Thu | Quality |
| Fri | Upper / mobility / rest |
| Sat | Hybrid / conditioning |
| Sun | Long easy |

**V1 implication:** With N training days, place quality mid-week and long at end of week (we already bias long to Sunday-ish). Later: user marks strength days so we don’t stack quality next to them.

## How to increase volume

Increase **gradually**. Change **one main variable at a time**.

Progression levers (pick one):

- Add time to short easy  
- Add time to long  
- Add one quality rep  
- Small bump to total weekly running  
- Hold intensity, raise volume — **or** hold volume, raise intensity  

Example:

| Week | Pattern |
|------|---------|
| 1 | Build |
| 2 | Build |
| 3 | Build |
| 4 | Lower-volume / freshen |

Progress = work that can be **absorbed**.

**V1 implication:** Monday roll + readiness (progress/hold/ease) should bump **one** of volume or quality density, not both. Cap weekly growth (~5–10%).

---

## Lower-volume weeks

Intentional deloads:

- Less total volume  
- Fewer reps  
- Shorter long  
- More easy  
- More recovery between keys  
- Reduced intensity when needed  

Simple model: **3 build + 1 lower**. Some athletes need deload sooner; response guides the plan.

**V1 implication:** Fatigue streak / skipped quality → ease week (we have deload hooks). Make every 4th week an explicit lower-volume template later.

---

## When to increase intensity

**Earn intensity.** Ready when:

- Easy runs feel controlled  
- Long is repeatable  
- Recovery between sessions is stable  
- Quality is consistent  
- Strength stays productive  
- Sleep / motivation steady  
- Soreness resolves normally  

Hold or ease when:

- Easy pace feels unusually hard  
- Flat for several days  
- Strength drops  
- Niggles recur  
- Quality becomes survival  
- Life stress high  
- Poor recovery between sessions  

**V1 implication:** Map Garmin signals (pace vs easy band, late fade, HR, missed/partial) onto these ready / not-ready rules before blending more toward race pace.

---

## Easy pace matters

Easy building is the foundation. For many athletes, easy is **slower than expected** — that is correct.

Feel: conversational, controlled breathing, rhythm, finish with something left.

Heat, terrain, fatigue, sleep, stress change how pace feels. Watch informs; athlete context decides.

**V1 implication:** Never prescribe easy near race goal when calibration pace is far slower. Prefer “easy relative to current T-anchor.”

---

## Heart rate and intervals as feedback layers

Useful markers together:

- Pace, RPE, breathing  
- HR response  
- Recovery between reps  
- Ability to repeat the session  
- Next-day feel  
- Whether the session supports the broader week  

HR alone is not enough.

**V1 implication:** Keep HR as soft signal (fatigue / too_hard), not the sole scorer.

---

## Key takeaways (checklist for our engine)

1. Structure and intent — every session has a job  
2. Individualize application of the same principles  
3. Goal first, then build the week  
4. Field-tested pace anchor before race-goal paces  
5. T-Pace (or equivalent) organizes zones  
6. Three runs/week is enough for many athletes  
7. Space quality away from heavy load  
8. Increase volume gradually; one variable at a time  
9. Intentional lower-volume weeks  
10. Keep easy easy  
11. Progress intensity only when recovering well  
12. Plan must be executable, recoverable, repeatable

## Recommended structured approach (for next engine iteration)

Align plan creation to this order:

```text
1. Goal          → event, date, outcome priority
2. Profile       → last-3 fitness + days available (+ later: load/stress)
3. Anchor        → T-pace / field pace from last-3 (or designated test)
4. Week skeleton → easy + quality + long (by days/week)
5. Paces         → bands relative to anchor; race goal as destination only
6. Progression   → volume first in base; intensity later when ready
7. Deload rhythm → every 3–4 weeks or on fatigue signals
8. Execute loop  → sync runs → score → adapt one lever → Monday rebuild
```

That matches the guide’s philosophy: **structure, intent, progression, recovery** — with the athlete’s current capacity as the floor and the race as the horizon.
